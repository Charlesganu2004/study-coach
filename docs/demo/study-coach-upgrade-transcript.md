# Study Coach upgrade walkthrough

This recording follows the actual application using a labelled local demonstration model.

## 00:00:00.000 Study Coach: an upgraded study workspace

This walkthrough uses a deterministic local model fixture. Every answer still travels through the real application service and its model transport.

## 00:00:07.000 Choose a connection

Connections lists the built-in models and supported provider templates. A custom endpoint lets you connect another OpenAI-compatible model.

## 00:00:12.000 Add a model connection

The visible connection name identifies the local demonstration fixture. No cloud account, real API key, or billing is used in this recording.

## 00:00:19.000 Save and select your study model

Saved connections show their model, endpoint, and readiness. Use model selects the connection for study, tests, and materials.

## 00:00:25.000 Import your source material

Import a document or screenshot, review the extracted text, then save it. This example imports original Markdown notes; videos require captions or a transcript.

## 00:00:32.000 Keep notes in your local workspace

The preview becomes a saved source only after Save source. Longer text imports are split into bounded source passages.

## 00:00:37.000 Ask a question from your notes

Study uses the selected connection. The original source quotation appears beside the answer so you can inspect its evidence.

## 00:00:44.000 Read the source, then check your understanding

This response is visibly labelled as a local fixture. The service verified its quotation against the saved notes before displaying it.

## 00:00:50.000 Build a practice test

Choose open response, multiple choice, fill in the blank, or a custom format. Choose one to thirty questions; larger tests are generated in smaller batches.

## 00:00:56.000 Answer one question at a time

Starting a test opens a focused question screen. Expected answers and solutions remain on the service until assessment or an explicit reveal.

## 00:01:02.000 Yellow: close, with another attempt

A partly correct explanation turns the test yellow and offers Try again. The solution remains hidden while you refine the answer.

## 00:01:09.000 Green: correct, with the reasoning

A complete explanation turns the test green. A semantically correct paraphrase is accepted, and the source-supported solution becomes visible.

## 00:01:16.000 Red: review an incorrect answer

An incorrect answer turns the test red, locks that outcome, and shows the solution and exact source passage for review.

## 00:01:23.000 See solution records a question to revisit

Reveal is also red. Looking at a solution does not count as answering correctly; the recorded outcome stays fixed.

## 00:01:29.000 Finish with a review list

The summary lists the result of each question. The topic review list is saved locally so you can return to ideas that need practice.

## 00:01:34.000 Create notes in your preferred style

Choose concise, detailed, Cornell, outline, study guide, or custom notes. Document type and instructions are saved with the material.

## 00:01:41.000 Keep editable notes and a source-supported diagram

Generated sections, the relationship diagram, and exact source passages stay together in your local library.

## 00:01:48.000 Download an editable Word document

The Word export contains native editable text, source passages, and a vector diagram. It is a real document download from the Rust service.

## 00:01:53.000 Open the print view to save as PDF

Save as PDF opens a clean printable view with notes, all flashcard answers, diagrams, and source passages. Choose Save as PDF in the print dialog.

## 00:01:59.000 Bring the notes into OneNote

Copy for OneNote prepares rich notes and the diagram. If browser clipboard access is blocked, a downloadable HTML file provides a manual copy-and-paste path.

## 00:02:04.000 Use flashcards for active recall

Create five flashcards from the same source collection. Open a card only after trying to recall the answer yourself.

## 00:02:11.000 Make an original mnemonic or study song

Memory aids map each letter or lyric back to a source fact. This feature creates original text; it does not generate audio.

## 00:02:18.000 Return to the ideas worth practicing

Your review list distinguishes correct attempts from topics to revisit. Saved notes, generated materials, connections, and progress survive reopening the app.

## 00:02:24.000 Study Coach: connect, practice, and keep the evidence

The recorded model responses are deterministic local fixtures. Real account availability, model behavior, and cloud quotas are not claimed by this demonstration.
