Testing foundations / local demonstration fixture

Recall cue: what is isolated?

A unit test checks one function in isolation. An integration test checks how components work together. Choose the test scope to match the behavior you want to inspect.

Worked structure: Arrange, Act, Assert

First arrange the inputs. Next act on the behavior. Finally assert the expected result. For a function test, prepare one input, call the function, and compare its result with the expected value.

Summary and self-check

Unit tests inspect one function in isolation; integration tests inspect interactions. Explain this distinction from memory, then check your explanation against the source passage.
